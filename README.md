# MathCraft
Here's a game built by LST and his dad, just for fun and to make a visualization of progress on understanding of math and logic

## 怎么玩 / How to play
- 打开 `index.html` 即玩（单文件，零依赖，无需服务器）
- `quick-test.js` 是无头自测脚本：`node quick-test.js`

## 文件 / Files
- `index.html` —— 数棋大冒险（游戏本体，单文件）
- `quick-test.js` —— 无头测试
